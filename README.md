# Job search extensions

Two unpacked Chrome extensions: `social-job-collector` discovers hiring leads, and `job-autopilot` assists with application forms. Pair them using the collector instructions.

This repository is a public-safe copy: personal profile and résumé content, résumé files, application logs, browser data, credentials and generated native-host paths are excluded. Add your own verified profile and résumé before use. Automatic submission, account creation, résumé tailoring and hands-free operation are off in these defaults. The application answer logic still contains assumptions specific to the original search, including India and Delhi NCR; review it before using it for someone else.

The collector scans loaded social posts and can miss jobs or treat different links as separate leads. Read each job and verify its requirements before applying. Some platforms prohibit automation and may restrict accounts.
