Behaviour

Claude: new questions and stuck pages

When a form asks something new, or a page won't move on (a date in the wrong format, a skill that didn't stick, an empty required box), the extension sends Claude the fields, the errors and your profile, resume and remembered answers. Claude corrects the fields using only those facts, and the extension submits on its own. Anything not on record still comes to you. Every Claude answer and fix is shown in the panel log and saved with the application.
One-time setup: in a terminal, run bash native/install.sh inside the extension folder, then reload the extension. Claude runs with all its tools switched off, so it can only answer. When your plan's usage limit is reached, the extension asks you instead until it resets.
Or use an API key instead (billed to the key; takes priority over the plan):
Your profile, resume text, remembered answers and the form's field values go to Anthropic with each request (passwords, ID numbers and similar fields are never sent). The key is stored unencrypted in this browser profile. Leave it empty to keep everything local.
